# Project 2 starter directories

This folder contains **four alternatives**, not one submission. Choose one: `python/`, `c/`,
`cpp/`, or `rust/`.

Complete the selected directory, then create `submission.tar.gz` from the contents of that
directory so its `Makefile` is at the archive's project root. Run `./make_submission.sh <c|cpp|python|rust>` from the
kit root to do this correctly for you; otherwise tar the chosen directory by hand the same way.
Do not submit this parent `starter/` directory or all four starters together.

See `docs/PROJECT2_PENDULARM.md` for the full requirements and student-facing handout.
There is no `make map` target for Project 2, and `make run` must respect the `ARM_SIM_LINKS`
environment variable (`"2"` or `"3"`, default `2`).
