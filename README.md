# Project 2 (Pendularm) — student kit

Everything you need for Project 2, without the rest of the course repo.

- **`docs/PROJECT2_PENDULARM.md`** — start here. The assignment handout: overview, learning
  goals, system architecture, and the full topic/service contract.
- **`docs/layouts/`** — one build/run skeleton reference per language.
- **`spec/ROSBRIDGE_PROTOCOL.md`** — the external TCP/JSON transport `docs/PROJECT2_PENDULARM.md`
  builds on, reused unchanged from Project 1.
- **`starter/`** — four alternative starting points (`c/`, `cpp/`, `python/`, `rust/`), each with
  a `Makefile` and a minimal skeleton. Choose **one**; see `starter/README.md`.
- **`make_submission.sh`** — run `./make_submission.sh <c|cpp|python|rust>` once your chosen
  starter directory builds and runs, to produce a correctly-shaped `submission.tar.gz` (its
  `Makefile` at the archive root, matching what the autograder expects).
